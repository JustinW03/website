Whitelist

So kommst du auf den Server

Der Server ist nur für die Community: Du brauchst Discord, einen Twitch-Follow bei JustinZockt03 und musst mindestens 18 Jahre alt sein. Die Freischaltung dauert nur ein paar Minuten.

Das brauchst du: Minecraft Java Edition (aktuelle Version empfohlen, ältere Versionen unter 1.21.5 werden abgewiesen), einen Discord-Account, einen Twitch-Account und ein Alter von mindestens 18 Jahren.

  1. Discord-Server beitreten

    Tritt dem Discord der JustinZocktCommunity (öffnet in neuem Tab) bei. Du musst Mitglied bleiben – wer den Discord verlässt, fliegt sofort von der Whitelist.

  2. Regeln lesen und akzeptieren

    Lies im Kanal #regeln die Serverregeln und klick auf „Gelesen, akzeptiert und ich bin 18+“. Damit stimmst du auch der Datenverarbeitung nach Punkt 8 zu.

  3. Twitch verbinden

    Klick im Kanal #freischalten auf Freischalten → Twitch verbinden und bestätige den angezeigten Code auf twitch.tv/activate. Dabei wird kein Passwort übertragen – nur dein Twitch-Name.

  4. JustinZockt03 auf Twitch folgen

    Der Bot prüft, ob du JustinZockt03 (öffnet in neuem Tab) folgst. Falls nicht, bekommst du einen Link zum Folgen und einen Knopf „Erneut prüfen“. Wer später entfolgt, wird automatisch wieder von der Whitelist entfernt.

  5. Mit dem Server verbinden und Code holen

    Füge in Minecraft unter Mehrspieler den Server play.justinzockt.de hinzu und verbinde dich. Du wirst noch abgewiesen und siehst auf dem Bildschirm deinen persönlichen Code (z. B. MK3-LZD).

    play.justinzockt.de

  6. Code im Discord eingeben

    Gib den Code im Discord ein. Du bist sofort freigeschaltet, bekommst die Rolle „Whitelist“ und kannst direkt losspielen.

Gut zu wissen

  • Ein Account pro Person: Ein Discord-Konto = ein Twitch-Konto = ein Minecraft-Account. Zweitaccounts nur mit Erlaubnis des Teams.
  • Kein VPN/Proxy: VPNs und Proxys werden automatisch erkannt und abgewiesen. Spielen Geschwister oder Mitbewohner im selben Netz, meldet euch kurz per Ticket.
  • Twitch-Subs bekommen automatisch den Sub-Rang (Tablist, Chat, Scoreboard).
  • Gebannte Accounts können sich nicht freischalten.
  • Mods: Nur Mods aus der Liste „Erlaubte Mods“ im Discord sind erlaubt – Überblick in den FAQ.

Dein erster Join

Du landest am Spawn und bekommst einen Start-Guide im Chat. Der Spawn ist komplett sicher: kein Schaden, kein PvP, keine Monster. Tipp: Lass ein Aufnahmeprogramm mitlaufen (z. B. OBS mit Replay-Puffer, NVIDIA ShadowPlay/Instant Replay, AMD ReLive, Xbox Game Bar), damit du Regelverstöße anderer beweisen kannst.
