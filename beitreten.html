Whitelist

So kommst du auf den Server

Der Server ist nur für die Community: Du brauchst Discord und einen Twitch-Follow bei JustinZockt03. Die Freischaltung dauert nur ein paar Minuten.

Das brauchst du: Minecraft Java Edition (aktuelle Version empfohlen, ältere Versionen unter 1.21.5 werden abgewiesen) oder Minecraft Bedrock (Handy, Tablet, Windows, Xbox, PlayStation, Switch – immer die aktuelle Version), einen Discord-Account und einen Twitch-Account.

Auf die Whitelist

  1. Discord-Server beitreten

    Tritt dem Discord der JustinZocktCommunity (öffnet in neuem Tab) bei. Du musst Mitglied bleiben – wer den Discord verlässt, fliegt sofort von der Whitelist.

  2. Regeln lesen und akzeptieren

    Lies im Kanal #regeln die Serverregeln und klick auf „Gelesen und akzeptiert“. Damit stimmst du auch der Datenverarbeitung nach Punkt 8 zu.

  3. Twitch verbinden

    Klick im Kanal #freischalten auf Freischalten → Twitch verbinden und bestätige den angezeigten Code auf twitch.tv/activate. Dabei wird kein Passwort übertragen – nur dein Twitch-Name.

  4. JustinZockt03 auf Twitch folgen

    Der Bot prüft, ob du JustinZockt03 (öffnet in neuem Tab) folgst. Falls nicht, bekommst du einen Link zum Folgen und einen Knopf „Erneut prüfen“. Wer später entfolgt, wird automatisch wieder von der Whitelist entfernt.

  5. Mit dem Server verbinden und Code holen

    Java: Füge in Minecraft unter Mehrspieler den Server play.justinzockt.de hinzu und verbinde dich. Bedrock: Verbinde dich mit bedrock.justinzockt.de, Port 15314 – wie das auf deinem Gerät geht, steht weiter unten. Du wirst noch abgewiesen und siehst auf dem Bildschirm deinen persönlichen Code (z. B. MK3-LZD).

    play.justinzockt.de

  6. Code im Discord eingeben

    Gib den Code im Discord ein. Bedrock-Spieler geben dabei ihren Xbox-Gamertag (Name des Microsoft-Kontos) an. Du bist sofort freigeschaltet, bekommst die Rolle „Whitelist“ und kannst direkt losspielen.

📱 Mit Bedrock spielen (Handy, Tablet, Windows, Konsole)

Der Server ist ein Java-Server, aber über Geyser und Floodgate kannst du auch mit der Bedrock-Edition mitspielen – auf derselben Welt, mit denselben Spielern. Du brauchst dafür kein Java-Konto, nur dein Microsoft-Konto (Xbox-Gamertag). Die Whitelist läuft genau wie oben über Discord.

Adressebedrock.justinzockt.de
Port15314
Namefrei wählbar, z. B. „JustinZocktCommunity“
bedrock.justinzockt.de Port 15314

ℹ️ Halte Minecraft immer auf dem neuesten Stand – sonst kann die Verbindung fehlschlagen. Manche Java-Funktionen sehen auf Bedrock etwas anders aus (z. B. Menüs oder Schilder), funktionieren aber. Es gelten dieselben Regeln. Mods und Addons mit Vorteilen sind auch auf Bedrock verboten (Mods).

Handy & Tablet (iPhone, iPad, Android)

  1. Minecraft öffnen

    Starte Minecraft und melde dich mit deinem Microsoft-Konto an.

  2. Server-Reiter

    Tippe auf Spielen und wechsle oben zum Reiter Server.

  3. Server hinzufügen

    Scrolle nach unten und tippe auf Server hinzufügen. Trage als Serveradresse bedrock.justinzockt.de und als Port 15314 ein. Der Name ist egal.

  4. Speichern & verbinden

    Tippe auf Speichern und danach auf den neuen Server. Beim ersten Mal siehst du deinen Freischalt-Code – weiter wie oben beschrieben.

Windows-PC (Minecraft für Windows / Bedrock)

  1. Richtige Version starten

    Starte im Minecraft Launcher Minecraft für Windows (Bedrock-Edition) – nicht die Java Edition. Spielst du Java, nimm einfach play.justinzockt.de.

  2. Server hinzufügen

    Spielen → Reiter Server → ganz unten Server hinzufügen. Adresse bedrock.justinzockt.de, Port 15314.

  3. Verbinden

    Speichern, Server anklicken, Code merken und im Discord eingeben.

Konsole: Xbox, PlayStation, Nintendo Switch

Auf Konsolen kann man in Minecraft keine eigenen Server hinzufügen – es gibt nur die vorgegebenen „Featured Server“. Mit einem kleinen Trick geht es trotzdem: BedrockConnect. Dabei stellst du an der Konsole einen anderen DNS-Server ein. Klickst du danach einen Featured Server an, öffnet sich stattdessen eine Serverliste, in die du unsere Adresse eintragen kannst.

⚠️ DNS-Adressen (Stand November 2026, laut github.com/Pugmatt/BedrockConnect (öffnet in neuem Tab)): Xbox und Switch: Primär 104.238.130.180, Sekundär 8.8.8.8. PlayStation: Primär 45.55.68.52, Sekundär 8.8.8.8. Alternative in Deutschland (betrieben von ZAP-Hosting): 134.255.231.119. Klappt eine Adresse nicht, findest du die aktuelle Liste auf der BedrockConnect-Seite. BedrockConnect ist ein freies Projekt und gehört nicht zu uns. Zurück stellst du DNS einfach wieder auf Automatisch.

Schritt 1: DNS an der Konsole ändern

  • Xbox (One / Series): Einstellungen → Allgemein → Netzwerkeinstellungen → Erweiterte Einstellungen → DNS-Einstellungen → Manuell. Primär 104.238.130.180, Sekundär 8.8.8.8.
  • PlayStation 5: Einstellungen → Netzwerk → Einstellungen → Internetverbindung einrichten → deine Verbindung → Erweiterte Einstellungen → DNS-Einstellungen Manuell. Primär 45.55.68.52, Sekundär 8.8.8.8 → OK und Verbindung testen lassen.
  • PlayStation 4: Einstellungen → Netzwerk → Internetverbindung einrichten → WLAN oder LAN → Benutzerdefiniert → IP-Adresse „Automatisch“ → DHCP-Hostname „Nicht angeben“ → DNS Manuell: Primär 45.55.68.52, Sekundär 8.8.8.8 → MTU „Automatisch“ → Proxy „Nicht verwenden“ → Verbindung testen.
  • Nintendo Switch: Systemeinstellungen → Internet → Interneteinstellungen → dein Netzwerk → Einstellungen ändern → DNS-Einstellungen Manuell. Primär 104.238.130.180, Sekundär 8.8.8.8 → Speichern.

Schritt 2: Über einen Featured Server zur Serverliste

  1. Minecraft starten → Spielen → Reiter Server.
  2. Einen der Featured Server anklicken, z. B. The Hive, Mineville, Lifeboat, Galaxite oder Enchanted. Statt des Servers öffnet sich jetzt das BedrockConnect-Menü.
  3. Dort Connect to a Server wählen und Adresse bedrock.justinzockt.de und Port 15314 eintragen. Mit „Add to server list“ speicherst du den Server für das nächste Mal.
  4. Verbinden – Freischalt-Code merken und im Discord eingeben.

Alternative für Xbox: App „MC Server Connector“

Auf der Xbox gibt es im Microsoft Store die kostenlose App „MC Server Connector“. Dort trägst du Adresse bedrock.justinzockt.de und Port 15314 ein und startest Minecraft über die App – der Server taucht dann im Reiter Freunde als LAN-Spiel auf. Für PlayStation und Switch gibt es so eine App nicht, dort nimmst du die DNS-Methode.

Klappt etwas nicht? Melde dich mit Gamertag und Konsole per Ticket in #tickets.

Gut zu wissen

  • Ein Account pro Person: Ein Discord-Konto = ein Twitch-Konto = ein Minecraft-Account. Zweitaccounts nur mit Erlaubnis des Teams.
  • Java oder Bedrock – nicht beides: Es ist immer nur ein Account gleichzeitig freigeschaltet. Einen Wechsel beantragst du per Ticket in #tickets. Deine Items darfst du vorher per Truhe oder über andere Spieler zum neuen Account bringen; Coins werden nicht übertragen (Regel 11.6).
  • Kein VPN/Proxy: VPNs und Proxys werden automatisch erkannt und abgewiesen. Spielen Geschwister oder Mitbewohner im selben Netz, meldet euch kurz per Ticket.
  • Twitch-Subs bekommen automatisch den Sub-Rang mit Vorteilen wie /ec, /craft und mehr Coins pro Stunde – alles auf Ränge & Vorteile.
  • Gebannte Accounts können sich nicht freischalten.
  • Mods: Nur Mods aus der Mod-Liste sind erlaubt. Unsicher? Frag vorher per Ticket in #tickets.

OBS mit Replay-Puffer, NVIDIA ShadowPlay/Instant Replay, AMD ReLive, Xbox Game Bar), damit du Regelverstöße anderer beweisen kannst.
